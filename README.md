## 🚀 Featured Projects

### [AI Interviewer using RAG](https://github.com/dharun200701/AI-Interviewer-using-RAG)

An AI-powered technical interview assistant built around a RAG pipeline. It uses **Sentence Transformers and FAISS** for retrieving relevant interview questions, with **FastAPI and React** for the application layer and **Ollama/Gemma 2B** for answer evaluation.

Key areas demonstrated:

* Role, experience, and difficulty-based question retrieval
* Semantic search with `all-MiniLM-L6-v2`
* FAISS vector search
* Candidate answer evaluation
* Score and technical feedback generation
* React frontend with FastAPI backend

### [AI Fraud Detection](https://github.com/dharun200701/AI-Fraud-Detection)

An interactive fraud-detection simulator using **XGBoost**, **SHAP**, and **Streamlit**.

The application:

* Accepts transaction-related inputs
* Predicts a fraud probability
* Classifies risk into Low, Medium, or High
* Uses SHAP to explain feature contributions
* Provides a fraud-awareness help section and quiz

### [Lifestyle Disease Risk Detector](https://github.com/dharun200701/Life_style_disease_risk_detector)

A web-based health-risk prediction application using a **Random Forest classifier**, **SHAP Explainable AI**, and a **Groq-powered assistant**.

The project combines:

* Flask backend
* Lifestyle and health parameter processing
* Sleep-related condition prediction
* SHAP-based explanations
* Risk assessment
* AI-generated lifestyle guidance
* Deployment through Render

> This project is documented in the repository as an educational/research application and not as a medical diagnostic system.

### [Brain Tumor Detection & AI Assistant](https://github.com/dharun200701/Brain_tumor_detection_using_DL)

A web application that accepts brain MRI images for analysis and includes an AI assistant powered through the **Groq API**.

Technologies used in the project include:

* Python
* Flask
* Flask-CORS
* HTML, CSS, and JavaScript
* Brain-tumor detection model
* Groq API

The repository explicitly positions the project for educational and research purposes.

### [Webcam Face Recognition & Guest Pass Logger](https://github.com/dharun200701/face-recognition-guest-pass)

A Python desktop application for webcam-based face enrollment and recognition with local access logging.

Key components:

* OpenCV webcam capture

* Local face-encoding storage
* SQLite access logs
* Recognized/Unknown status tracking
* Logging cooldown to reduce duplicate entries

My projects tend to follow an end-to-end structure:

```text

Preprocessing / Feature Extraction

  ↓
Prediction / Retrieval / AI Response
  ↓
API or Application Layer

User-facing Result
```

Where appropriate, I also add explainability, evaluation, logging, or deployment components rather than keeping the work limited to a standalone model.
